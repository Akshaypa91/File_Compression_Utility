8. Limits
The test suite is dedicated to Worklet 1's core Huffman tree and code-length module (huffman_tree.h,
huffman_tree.cpp, min_heap.h, min_heap.cpp). The following were intentionally not tested:
1. Real end-to-end W2 (LZ77 match finder) and W3 (container format / CRC-32 / CLI pipeline) workflows.
2. Full block emissions and high-level token planning in huffman.cpp (plan, emit, decodeBlock).
3. Low-level BitWriter buffer overflows or streaming I/O outside BitReader bit consumption tests.
4. Multi-threaded concurrency (MinHeap and Huffman construction are designed as thread-isolated single-instance routines).
5. External static analysis tools (e.g. Clang-Tidy, Cppcheck, Coverity).
6. Other host architectures, operating systems, or endianness variants.
All fixes were verified solely against this test suite, the sanitizer build configuration, and gcov coverage analysis.
